# plan-AOB一键更新同步功能-20260523-001

## 1. 目标

按 design 文档完成 AOB 一键更新能力，交付：

1. 新 CLI 子命令 `update-user-content`。
2. tools API 与事务模式接入。
3. 数据库优先比较 + 回退比较。
4. 新增/更新/删除三类同步。
5. 测试与手册同步。

## 2. 阶段拆分

### 阶段 A：核心数据模型与 registry 表

交付：

1. 在 `library_tool.py` 增加逻辑条目扁平化与反扁平化辅助函数。
2. 新增 `user_content_sync_registry`、`user_content_sync_target_files` 表初始化与读写。
3. 实现“数据库优先 + 回退时间戳”的胜出决策函数。

验收：

1. 可对 libs 和任意目标 AOL 快照产出稳定决策结果。
2. 数据库可重复运行，不报 schema 冲突。

### 阶段 B：update-user-content 主流程

交付：

1. 新增 `更新用户级内容(...)` 主函数。
2. 支持读取 libs canonical 与目标侧 AOL 快照，合成最终 canonical。
3. 支持写回 canonical、发布到全部目标。
4. 支持托管文件清单删除同步。

验收：

1. dry-run 与 real-run 行为一致（除落盘外）。
2. 新增/更新/删除统计正确。

### 阶段 C：CLI、tools、事务接入

交付：

1. `library.py` 命令支持 `update-user-content`。
2. `run_aob_update_user_content(...)` 与 `aob_update_user_content(...)`。
3. `AOB统一业务事务` 新增 `update_user_content` 模式。

验收：

1. 一行命令可运行。
2. 事务 mode 可运行。

### 阶段 D：测试与文档

交付：

1. 新增 `tests/test_aob_user_content_update.py`。
2. 更新 `docs/API手册.md`、`docs/用户手册.md`、`docs/开发者指南.md`。
3. 记录本轮任务文档。

验收：

1. 相关测试通过。
2. 文档口径与实现一致。

## 3. 详细任务清单

1. 在 `library_tool.py` 实现：
   - snapshot 扁平化。
   - registry 读取/更新。
   - 决策合成。
   - final canonical 生成。
   - 目标发布与托管删除。
2. 在 CLI 层接入 `update-user-content` 参数。
3. 在 `autodokit.tools.aob` 与 `tools/__init__.py` 增加导出。
4. 在 `AOB统一业务事务/affair.py` 与 `affair.json` 增加模式与默认参数。
5. 编写单测，覆盖新增、回流、删除、dry-run。
6. 更新三份手册。

## 4. 验证计划

执行顺序：

1. `pytest tests/test_aob_user_content_update.py`
2. `pytest tests/test_aob_user_content_aggregate.py tests/test_aob_user_content_publish.py tests/test_aob_user_content_update.py`
3. `python scripts/aob_tools/library.py update-user-content --dry-run`

验证重点：

1. registry 记录是否更新。
2. 决策摘要是否符合预期。
3. 删除同步是否仅作用于托管文件。

## 5. 风险控制

1. 删除风险：仅根据托管文件表删差量，不全盘清理。
2. 首次运行判定偏差：明确输出 fallback 计数，建议先 dry-run。
3. 兼容风险：聚合/发布原命令保持不变，不改变原默认行为。

## 6. 预计产物

1. 代码：核心 runtime + 入口 + 事务接入。
2. 测试：新增 update 测试并通过。
3. 文档：设计、计划、API、用户手册、开发者指南、任务记录。
